# Resolving the hardware evidence gaps

The model describes a representative academic terminal. The vendor folder is the team's research handoff, not a manufacturer's package for a built tank. It already supplies tank dimensions, roof family, representative geometry, fitting counts and operating choices. Those choices stay DESIGN/SIM; public product descriptions do not convert them into measured hardware properties. No diagnostic agent is needed for this work.

## Choose a coherent reference installation

There are two defensible routes. Obtain an engineering reference package matching the selected tank and equipment, or deliberately revise the representative plant to a fully documented published installation or manufacturer reference design. A real operating terminal and private historian are not mandatory. The replacement must have enough drawings, properties, test conditions and calculations to support the mechanisms being simulated. A brochure alone is insufficient.

The first route preserves the present M1 basis: 30 m tank shell, 29.7 m effective deck, suspended full-contact honeycomb roof, mechanical-shoe primary and secondary wiper families. These are existing team choices, not newly selected dimensions. The 20 kg/m2 mass proxy is not an HMT rating. The 150 mm gap is a team choice informed by another vendor's example. Neither should be supplied to a structural model as a measured property.

If a supplier's reference design differs, record the differences and revise the whole affected model through versioned configuration changes. Do not scale a different roof's capacity by diameter, multiply an allowable load by a guessed safety factor to obtain failure strength, or mix one manufacturer's panel with another's unverified attachments. Regenerate new cases after the change; preserve the old data as historical research.

## Resolve the suspension drawing conflict first

M1 explicitly specifies six suspension-penetration groups. [HMT's suspension description](https://www.hmttank.com/news/make-the-right-design-choice-to-engineer-safety-into-your-tanks/) describes an option without deck penetrations. That public option cannot establish either six EPA leg wells or zero openings for the present model. Ask the roof designer to identify each gas path on the selected drawing. Either keep six actual penetrations and supply their geometry/closure, or explicitly revise the team configuration to a documented nonpenetrating arrangement. The current routine adapter rejects a no-opening hanger factor for those six existing penetration groups.

The [HMT HFC](https://www.hmttank.com/products/internal-floating-roofs/full-contact/aluminator-hfc-ifr/), [ALLENTECH primary shoe](https://www.hmttank.com/products/floating-roof-seals/internal-primary/allentech-primary-shoe-seal/) and [VaporFlex secondary](https://www.hmttank.com/products/floating-roof-seals/internal-secondary/vaporflex/) pages identify the requested families. Use the manufacturer's engineering/quote contact on those pages to request an academic reference design, configuration-specific drawings and available test evidence. No supplier has been contacted by the software.

## Instrument checks before adopting a specification

[Yokogawa's EJA110E specification](https://www.yokogawa.com/pdf/provide/E/GW/GS/0000026251/0/GS01C31B01-01EN.pdf), June 2026 edition, gives capsule-dependent ranges and reference accuracy. The H capsule has a maximum 500 kPa span; the proposed -1 to +5 barg range spans 600 kPa. The V capsule covers other spans but has a different expression below its stated 1,400 kPa reference breakpoint. A 0 to 10 barg span also lies below that breakpoint. Consequently the generic +/-0.055% figure does not qualify all of the team's proposed ranges. Request the actual capsule, calibrated lower/upper values, pressure connection/basis, materials/fill and applicable performance calculation. Do not auto-select a capsule or transfer its bound into the existing synthetic noise model.

The [Rosemount 5900S data sheet](https://www.emerson.com/is/content/emerson/en/measurement-instrumentation/technical/products/level/documents/doc-rosemount-00813-0100-5900.pdf) identifies instrument accuracy; it does not establish the installed antenna/well, reference datum, manual dip-tape accuracy or an acceptance rule for this tank. Request the selected antenna/well arrangement, gauge reference height/datum and calibration/verification procedure. [NIST TN1297](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-6-expanded-uncertainty) defines expanded uncertainty through a coverage factor; it does not make every quoted accuracy bound a k=2 interval or define good/bad equipment.

## Submission and adoption sequence

1. Send the relevant rows above and the known M1 design to the supplier/designer. State that this is an academic reference simulator and ask which details are public, available under an academic agreement, or unavailable. Ask for exact model/configuration, document number, revision, units, conditions and limitations. Request engineering drawings and test/calculation evidence rather than a statement that a product meets a standard.
2. Save the returned source documents unchanged in a separate evidence folder. Keep document filenames, publication/revision, applicable asset/model and page/table locators. Curves need axis units, pressure basis and reference gas/temperature; a standard-volume flow curve requires its stated reference conditions before conversion to mass flow.
3. Export the request and blank response, fill configuration identity/applicability and list each source file with its SHA-256, scope and page/table locator. Run the document-binding check below. A successful check means files are identified and unchanged, not that their engineering content is sufficient.
4. Have the relevant mechanical, venting, emissions or measurement reviewer check that the content matches this installation, covers each requested quantity and supports the intended model. Extract scalar values as source-bearing ParamValue records and curves as versioned data with units and uncertainty. Values not actually supplied remain OPEN. A document's working-load limit is not relabelled ultimate rupture strength.
5. Implement any genuinely new mechanism from those reviewed inputs. Verify geometry/units, conservation, equilibrium, load redistribution, pressure/flow limits, numerical refinement and the applicable manufacturer/reference cases. Check pressure and material-validity limits. A source attachment does not itself implement or validate a model.
6. Generate a new prospectively sampled version with full process/inspection coverage, retain rejected/no-child/inconclusive outcomes, and run the existing engineering, observability and split/shortcut qualification checks. Keep parent-related cases in one split. Neither this document intake nor the new vapour methods opens the production or physical training gates.

## If detailed failure data cannot be obtained

Do not manufacture positive cascade examples. Keep the coupled restrained-roof reference, with its declared pressure-equalized boundary, as a restricted mechanics case; omit unsupported rupture and damaged-emission targets from physical training. Independently injected component faults may be retained as explicitly synthetic experiments, with null causal parents rather than a fabricated causal chain. An independently documented alternative design is another route, but it requires a coherent design revision and new validation. Narrowing scope is a defensible release decision only when the resulting dataset has passed its own qualification; it does not retroactively validate the archived mechanical extension.
